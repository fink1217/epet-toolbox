# PENG! 數位戲台

電子雞開放架構平台。PENG! 就是戲台：台子自己焊、角色自己畫，按一下燒進去，角色就上台（ESP32-S3-Touch-LCD-1.47）。

品牌圖形（戲台標誌、像素角色）都在 `web/js/svg/stage.js`；拿到正式 Logo 向量檔時只要換那一個檔，favicon 再從它重新產生。

**線上使用：** https://fink1217.github.io/epet-toolbox/
（請用電腦版 Chrome 或 Edge；刷韌體與直接寫入 SD 卡只有這兩個瀏覽器支援）

| 頁面 | 內容 |
|---|---|
| ① 接線教學 | 一步一張圖焊好整組電路，每一步都能翻正反面、指到孔會亮出整條管路，最後有完整接線總圖 |
| ② 素材生成器 | 丟進 AI 畫的角色、背景、音效（角色動作也可以丟 MP4 影片），自動去背、切格、對齊，存進素材資料夾 |
| ③ 寫入裝置 | 一鍵刷韌體（Web Serial）、一鍵把素材打包進 SD 卡 |

兩個版本：**商品版**（觸控螢幕、自己焊馬達驅動）與**自玩版**（加 EC11 旋鈕、用震動馬達模組）。

## 在自己電腦上開

雙擊 `開啟工具.bat`（需要 Python），或在 `web/` 資料夾執行：

```
python -m http.server 8765
```

再用瀏覽器開 http://127.0.0.1:8765/ 。不要直接雙擊 `web/index.html`，瀏覽器會擋掉網頁的程式。

## 目錄

| 位置 | 內容 |
|---|---|
| `web/` | 網頁工具本體（純前端，沒有建置步驟） |
| `web/js/data/` | 唯一資料來源：主板腳位（`boards.js`）、小電路板配置（`hub.js`）、素材詞彙（`vocab.js`） |
| `docs/` | SD 卡格式 v1、素材資料夾規則 |
| `tools/` | 檢查與測試工具 |

## 檢查

```
npm test
```

- 小電路板線路檢查：四種配置（觸控／旋鈕 × 裸馬達／模組）都要沒有斷路、沒有短路、沒有漏教的步驟
- 素材資料夾讀取規則
- 打包器（QOI 編碼、點陣字型、MD5）

推上 `main` 時 GitHub Actions 會先跑 `npm test`，通過才部署網頁。
