# 素材資料夾規則

素材資料夾是學員自己的東西：用中文命名、放高解析母檔。生成器寫入這個資料夾，打包器讀取這個資料夾。

```
我的戲台素材/                 ← 名稱隨意
├── 寵物.json               名字、每個動作的幀率、自訂文字（生成器會維護，不用手寫）
├── 角色/
│   ├── 待機/001.png 002.png …     1024×1024 透明 PNG，腳底踩在 y=984、水平置中
│   └── 吃東西/001.png …
├── 背景/白天.png            1080×1920 直式 PNG
├── 圖示/餵食.png            512×512 透明 PNG
├── 道具/食物.png            512×512 透明 PNG
└── 音效/吃東西.wav          任何取樣率的 WAV 或 MP3
```

- **資料夾名稱就是動作名稱**，裡面的檔案依檔名排序就是播放順序。
- 能用的中文名稱見 `web/js/data/vocab.js`。不認得的名稱，打包器會提醒並略過，不會報錯中斷。
- 必要的只有兩樣：`角色/待機/` 和 `背景/白天.png`。

## 寵物.json

```json
{
  "format": 1,
  "name": "小黃",
  "anims": { "待機": { "fps": 6 }, "吃東西": { "fps": 8 } },
  "texts": { "lines": { "hungry": ["餓扁了"] } }
}
```

全部都可以省略，省略就用預設值。
